OUR LITTLE WORLD ♡

HOW TO OPEN
1. Extract this ZIP file.
2. Keep index.html, style.css, script.js, captions.js and the images folder together.
3. Open index.html in a web browser.

PHOTOS
The gallery uses the original 70 photo files in the images folder. Do not rename or move them.

CAPTIONS
All 70 captions are stored in captions.js in photo order. The wording has been kept as supplied; only the first letter of each caption has been capitalised. Longer captions wrap onto extra lines and use a smaller font.

COUNTER
The counter starts at 11 May 2023, 7:30 PM Sri Lanka time. Use the button to switch between the years/months/weeks display and total elapsed days display.

For best results, upload the whole folder to a static website host rather than uploading index.html alone.
